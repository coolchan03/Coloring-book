# Coloring pages

Each folder here is a category; each image inside it is a page. White (and near-white)
is made transparent in the browser, so any black-on-white line art works as-is.

## Add pages

1. Drop `.svg`, `.png`, `.jpg` or `.webp` files into a category folder (create a new folder for a new category).
2. Run `python3 tools/build_manifest.py` from the repo root.
3. Commit and push. The site redeploys automatically.

Prefer line art with **closed outlines** (no gaps), because the bucket fill is bounded by the lines.
